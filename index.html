⏳ 2. Splash Screen 🎬

Independent splash screen that awaits completion before building the window.

splash.lua 
local splash = Library.Splash({
    Text = "Your Logo Name", 
    Font = "Bangers", 
    Color = "Cyan",
    BackgroundColor = "Dark", 
    Size = 200, 
    TextSize = 40,
})
splash:Wait()

🪟 3. Window & Tags 🏷️

Create the core script window with custom themes and version tags.

window.lua 
local Window = Library.CreateWindow({
    Title = "Pro Interface", 
    Icon = "home", 
    Theme = "Green",
    ToggleKey = Enum.KeyCode.RightShift,
})
Window:Tag({ Title = "v2.0", Color = "Blue" })

📁 4. Sections & Tabs 📑

Organize elements neatly using inner tabs and sections.

tabs.lua 
Window:Section("Main Section")
local Main = Window:CreateTab("Home", "home")
Main:CreateSection("Core Elements")

🖱️ 5. Buttons ⚡

Add interactive buttons with automatic notifications.

button.lua 
Main:CreateButton("Button Name", "Description here", function() 
    Library.Notify("Success", "Button Clicked!", nil, 3, "success") 
end)

🎚️ 6. Toggles & Checkboxes ☑️

Standard toggle switches and custom checkbox elements.

toggles.lua 
Main:CreateToggle({ Name = "Enable Feature", Default = false, Flag = "enabled", Callback = print })
Main:CreateToggle({ Name = "Checkbox Style", Type = "Checkbox", Callback = print })

🎛️ 7. Sliders 📊

Control numeric values and speeds smoothly.

slider.lua 
Main:CreateSlider("WalkSpeed", 0, 100, 16, 1, print)

📋 8. Dropdowns 🗂️

Single and multi-selection dropdown lists.

dropdowns.lua 
Main:CreateDropdown("Select Option", { "A", "B", "C" }, print)
Main:CreateMultiDropdown("Multi Select", { "X", "Y", "Z" }, print, { "X" })

⌨️ 9. Keybinds 🎮

Bind custom actions to keyboard keys.

keybind.lua 
Main:CreateKeybind("Bind Key", Enum.KeyCode.F, function() 
    print("Key F Pressed") 
end)

📝 10. Notes, Labels & Paragraphs 📌

Display colored notes, text labels, and informative paragraphs.

texts.lua 
Main:CreateNote("Blue Notice Box", "Blue")
Main:CreateNote("Dark Notice Box", "Dark")
Main:CreateLabel("Simple Text Label")
Main:CreateParagraph("Title Header", "Long explanatory text goes here", "info")

📈 11. Progress Bars & Code Snippets 💻

Visual progress indicators and inline code preview blocks.

progress_code.lua 
Main:CreateProgress("Loading Progress", 0, 100, 40)
Main:CreateCode("Example Snippet", "print('hello world')")

💬 12. Dialog Prompts ⚠️

Popup confirmation dialog boxes for users.

dialog.lua 
Window:Dialog({
    Title = "Confirmation Alert", 
    Content = "Do you want to proceed?", 
    Icon = "info",
    Buttons = {
        { Title = "Yes", Variant = "Primary", Callback = function() end },
        { Title = "No", Variant = "Secondary" },
    },
})

💾 13. Config Management ⚙️

Automatically save and load element configurations using flags.

config.lua 
Window:SaveConfig("default")   -- Saves all elements with flags
Window:LoadConfig("default")
